# Experiencia-Pratica-2-Instituto-Futuro-Solidario 🌱

Um site institucional responsivo e acessível para uma organização sem fins lucrativos, desenvolvido com HTML5, CSS3 (com Design System) e JavaScript puro.

![Preview do site](https://obscure-lamp-g4w7j6jj4wjqfp4q9-8000.app.github.dev/)

## ✨ Funcionalidades

- ✅ Design responsivo (mobile-first)
- ✅ Menu hambúrguer com dropdown
- ✅ Sistema de grid customizado (12 colunas)
- ✅ Design System com variáveis CSS
- ✅ Paleta de cores e tipografia definidas
- ✅ Formulário de cadastro de voluntários
- ✅ Imagens embutidas em Base64 (funciona offline)
- ✅ Totalmente acessível (ARIA, semântica, foco)

## 🛠️ Tecnologias Utilizadas

- **HTML5** – Estrutura semântica
- **CSS3** – Grid, Flexbox, variáveis, media queries
- **JavaScript** – Menu mobile interativo
- **Design System** – Cores, espaçamento, tipografia
